# 指令版：sourcing-costing

> 用途：资源询价与成本报价。按方案的资源需求生成询价单、记录公开平台参考价，把供应商报价录入报价记录并统一口径，比较取舍，用成本测算表按服务模块和三档人数测算、核对易漏项和最低安全报价，准备对客报价单内容，处理报价失效和供应商变化。金额只在表格中计算。

> 使用方法：作为项目或智能体的指令，或放进任务包。通用规则见 shared-rules.md；project-hub 的场景见 scenarios.md。

## 6 验收

- 每个价格都有报价编号和价格状态；参考价没有被当作正式报价使用。
- 测算表每一行都有服务模块编号；数量依据清楚（按人数或固定数量）。
- 易漏项逐项核对过；未知费用标"待查估算"，没有填零。
- 三档人数都有结果；低于最低安全报价或含参考价时有明确提示。
- 对客报价单不含内部成本、供应商名称和毛利（D09 §9）。

常见失败：口径不一致就直接比较总价；忽略供应商报价里的"不包含"；在文字里心算金额；报价过期未发现。

# 成本测算表使用说明

版本 v1.0 · 方法层 · 属于 sourcing-costing（S04） ｜ 工具 X01

---

## 1 文件

- 模板：`templates/X01-cost-calculator.xlsx`（不直接填写模板，复制后使用）。
- 项目副本：`03_资源与报价/{项目编号}_成本测算_V{n}_{YYYYMMDD}.xlsx`。
- 黄色格子填写，灰色格子是公式。

## 2 工作表

| 工作表 | 内容 |
|---|---|
| 说明 | 使用方法 |
| 参数 | 项目编号、版本、计划人数、低档与高档系数（默认 0.8、1.2）、报价口径、毛利底线、风险预备比例、三档拟报价 |
| 成本明细 | 每行一个费用项（预置 100 行） |
| 汇总 | 三档的成本合计、参考价金额、待查估算金额、风险预备、最低安全报价、拟报价、毛利、毛利率、人均报价和提醒 |
| 模块 | M01–M16 |

## 3 成本明细怎样填

| 列 | 填法 | 例子 |
|---|---|---|
| 模块编号 | D05 §7 | M03 |
| 费用项 | 具体名称 | 酒店标准间（双人间） |
| 报价编号 | A04 的编号；参考价也要填来源编号 | Q-261101-01 |
| 价格状态 | 参考价、正式报价、已核可用、已锁定、已结算、已失效、待查估算 | 正式报价 |
| 单价 | 与报价的计价单位一致 | 480 |
| 计量方式 | 按人数（数量随人数变化）或固定数量 | 按人数 |
| 系数或数量 | 按人数时填每人系数；固定数量时填数量 | 0.5（两人一间） |
| 次数 | 天数、晚数或场次 | 2（两晚） |
| 向上取整 | 房间、车辆等需要整数时填"是" | 是 |
| 含税 | 是、否、未知 | 是 |

计算公式：

- 按人数：数量 = 人数 × 系数（需要时向上取整）× 次数
- 固定数量：数量 = 系数或数量 × 次数
- 小计 = 单价 × 数量

## 4 常见写法

| 费用 | 计量方式 | 系数 | 次数 | 取整 |
|---|---|---|---|---|
| 双人间住宿 | 按人数 | 0.5 | 晚数 | 是 |
| 单人间住宿 | 按人数 | 1 | 晚数 | 否 |
| 正餐 | 按人数 | 每天餐数 | 天数 | 否 |
| 45 座大巴 | 按人数 | 1/45 ≈ 0.0223 | 天数 | 是 |
| 主会场 | 固定数量 | 1 | 天数 | 否 |
| 讲师 | 固定数量 | 讲师人数 | 天数或课时 | 否 |
| 保险 | 按人数 | 1 | 天数（按天计时） | 否 |

## 5 计算结果怎样取得

- 有 Excel 或 WPS：打开文件即自动计算；保存后文件里才有计算结果。
- 没有 Excel：运行 `python3 scripts/cost_recalc.py {测算表} --out {同名}_摘要.md`（方法库中为 tools/cost_recalc.py），按同样的公式复算并输出摘要（需要 openpyxl）。
- 都不能用：输出测算输入表（Markdown），请人在表格中填写（D06 §11）。

## 6 引用

对外报价和方案中的金额都写"成本测算 V{n}"；脚本复算时写"成本测算 V{n}（脚本复算）"。不在其他文件里另算金额（D09 §1）。

# 资源询价与成本报价：模式

版本 v1.0 · 方法层 · 属于 sourcing-costing（S04）

---

## M1 寻源与询价〔T2〕

适用：SC20、SC21；SC14、SC15 的资源询价。

1. 读资源需求清单，按服务模块分组。
2. 每个需求在 A03 中找候选资源：同地区、规格容量合适、状态"可用"、评价好的优先；记录候选理由。
3. **公开平台查价**（SC21）：记录平台、查询时间、产品、日期、条件、价格；录入 A04，价格状态"参考价"。
4. **询价单**（TP10）：统一写清日期、人数、规格、数量、计价单位；请供应商说明含税、包含与不包含、起订条件、取消条款、有效期、档期。只写报价需要的信息，不写客户名称（D07 §3）。
5. 列出发出对象和回复截止时间，由人发出（D06 §7）。

## M2 报价录入与归一〔T2〕

适用：SC22；SC35 的状态更新。

1. 每份报价录入 A04 一行或多行（D05 §9.3 字段）；原件存 `03_资源与报价/` 或 `01_原始资料/`。
2. 价格状态：书面、有有效期 → "正式报价"；口头或模糊 → "参考价"。
3. **统一口径**：同一计价单位、同一数量、同一含税口径；报价里缺的项目列为"待查"，不当作 0。
4. 预订或付款后（SC35），提出状态更新建议："已核可用"或"已锁定"，由资源采购确认。

## M3 比较与取舍〔T2 归一；T1 取舍〕

适用：SC22；SC17 需要改资源时。

1. 填 TP11：原始报价、统一口径后的单价和小计、包含与不包含、待查项、有效期、条件与风险、体验与服务、历史评价。
2. **差额从哪里来**：价格本身、包含范围、数量口径、条件（取消、起订）、风险。
3. **取舍**〔T1〕：结合客户目标和体验，说明多花的钱换来了什么、少花的钱放弃了什么。
4. 写出建议和理由；由负责人选择（D06 §7）。

## M4 测算与情景〔T2 填表；T3 计算〕

适用：SC23；SC02 第 3 步；SC31 第 3 步；SC10 粗测。

1. 复制 `X01-cost-calculator.xlsx` 到 `03_资源与报价/{项目编号}_成本测算_V{n}_{YYYYMMDD}.xlsx`（已有版本时版本号加一）。
2. 参数页：项目编号、版本、计划人数、报价口径、毛利底线、风险预备比例、三档拟报价（公司参数未定时留空）。
3. 成本明细页：每行一个费用项，填模块编号、报价编号、价格状态、单价、计量方式、系数或数量、次数、是否取整。
4. 核对易漏项（D09 §3），缺的补"待查估算"行。
5. 计算：表格自动计算；或运行 `python3 scripts/cost_recalc.py {文件} --out {同名}_摘要.md`（T3）。
6. 看汇总页的提醒：低于最低安全报价、含参考价、已失效报价、缺报价编号 → 写入异常说明〔T1〕。
7. 结果摘要写明"成本测算 V{n}"（脚本复算时加"脚本复算"）。

## M5 报价单准备〔T2〕

适用：SC25；SC02 第 4 步。

1. 从测算表取选定档位的报价，注明版本。
2. 按 TP12 写报价单内容：依据、明细（按模块，对客口径）、包含、不包含、有效期、说明；填"关键数据"块。
3. 检查 D09 §9：不出现内部成本、供应商名称、毛利。
4. 交 deliverable-production M4 排版；由负责人或财务审批。

## M6 报价变化〔T2；影响大时转 change-review M4〕

适用：SC24。

1. 更新 A04：过期 → "已失效"；涨价 → 新报价编号；撤回 → "已失效"并备注。
2. 找出引用该报价编号的测算表版本和成果（看主卡版本指针）。
3. 估算影响金额（在测算表中复制新版本计算）。
4. 列出替代资源（M1）。
5. 影响达到重大变更阈值，或已对客报价时，转 change-review M4。
