# 指令版：planning-design

> 用途：策划与方案设计。为会议活动、培训学习、客户活动、出行福利（定制游、研学、游学、疗休养、团建）项目生成 2–3 个实质不同的策划方向，细化选定方向的方案结构（模块组合、行程议程课表、资源需求），制作风格卡与主视觉、编辑图片，审查方案，处理"更高级但预算不变"一类的含糊反馈。

> 使用方法：作为项目或智能体的指令，或放进任务包。通用规则见 shared-rules.md；project-hub 的场景见 scenarios.md。

# 策划与方案设计（S03）

版本 v1.0（2026-11-09） ｜ 默认层级 T1（GPT）

## 1 何时使用，何时不用

- **使用**：SC13–SC16 策划；SC17 含糊反馈；SC18 风格与主视觉；SC26 第 2 步方案审查。
- **不用**：按已定方向写成文（交 deliverable-production）；按风格卡批量延展图片（交 deliverable-production M7）；算钱（交 sourcing-costing）。

## 2 输入

- **必需**：项目主卡（目标、受众、人数、日期、预算、硬性要求）；主产品族。
- **可选**：A06 客户偏好；A07 同类优秀方案与策划片段；需求与评分矩阵（招投标项目）；资源概况（A03）。
- **主卡关键条件缺失**：可以先出方向，但每个方向都写明"依赖的假设"；缺目标或人数时，建议先走 brief-analysis M3。

## 3 调用的资产与模板

策划卡（`references/cards/`，按主产品族选用）；A07；A06；需求与评分矩阵。模板：TP08 方向对比与方案结构、TP09 风格卡、TP07 策划卡结构（新增产品族时用）、TP03。

## 4 处理步骤

| 步 | 动作 | 层级 |
|---|---|---|
| 1 | 读主卡、策划卡、需求矩阵；明确主目标和成功标准 | T1 |
| 2 | 按 `references/modes.md` 选模式：M1 方向生成、M2 方案结构、M3 风格与主视觉、M4 方案审查、M5 含糊反馈 | T1 |
| 3 | 按模式产出；每个设计选择都对应客户目标和约束 | T1 |
| 4 | 列出需要人决定的事项（方向、视觉） | T1 |
| 5 | 把资源需求清单交 sourcing-costing；把成文工作交 deliverable-production | T1 → T2 |

## 5 产出

- `04_策划与设计/{项目编号}_方向与结构_内部_V{n}_{版本状态}_{YYYYMMDD}.md`（TP08）。
- 风格卡（TP09）与图片：`04_策划与设计/视觉/`，每张图片配同名 .md（平台、提示词、用途、"示意"）。
- 审查意见：写在交接卡或单独的审查记录中。

## 6 验收

- 方向之间有实质差异（核心体验、内容深度、节奏、资源组合、预算结构中至少两项不同），不是只换名字。
- 每个方向写明资源（服务模块）、预算压力、主要风险和适合条件。
- 方案结构的日程可以执行：交通时长、场地容量、时间衔接合理。
- 没有写进未经确认的资源、价格或效果承诺。
- AI 图片标"创意示意"（D10 §4）。

常见失败：方向雷同；忽略预算和日期约束；把概念图当成实景；方案结构没有对应服务模块，导致询价和执行无法衔接。

## 7 回写

建议写入：主卡 §4（选定方向、差异化要点，人选定之后）；A07（复盘时再决定是否入库）。

## 8 平台差异与替代

按 D06 §11。在执行层降级执行时，成果第一行标"【降级执行：未经 T1 审查】"（D06 §4.3）。不能生成图片时，输出风格卡和提示词，交给有能力的平台。

- 口令：给 018 出三个方向 ／ 按方向 B 细化行程 ／ 做 018 的风格卡和主视觉 ／ 审查方案 V2 ／ 客户说要更高级但预算不变

# 策划与方案设计：模式

版本 v1.0 · 方法层 · 属于 planning-design（S03）

全部为 T1。在执行层降级执行时，按 D06 §4.3 标注。

---

## M1 方向生成

适用：SC13–SC16 第 1 步。

1. **定目标**：写出主目标（D05 §8.3）和可以观察的成功标准（例如"参会者能说出三个合作方向""学员结业考核通过率"）。
2. **列约束**：预算、日期、人数、地点、硬性要求、评分要点（招投标）。
3. **找参照**：A07 中同产品族、同客户类型的方案；A06 客户偏好。参照只用来借鉴，不照搬。
4. **生成 2–3 个方向**，至少在两个维度上实质不同：
   - 核心体验（例如：高效会务／文化体验／团队共创）
   - 内容深度（轻松／专业）
   - 节奏（紧凑／舒缓）
   - 资源组合（服务模块的组合方式）
   - 预算结构（钱主要花在哪里）
5. **每个方向写清**：一句话主张、核心体验、关键环节、资源（模块）、预算压力、主要风险、适合条件。
6. **对比与推荐**：填 TP08 第一部分，写出推荐和理由；明确"需要负责人选择"。

## M2 方案结构

适用：选定方向之后。

1. **模块组合**：按 D05 §7 列出用到的服务模块和每个模块的内容。
2. **日程**：行程、议程或课表，精确到时段；检查交通时长、场地容量、时间衔接、用餐和休息。
3. **体验设计要点**：开场、高潮、收尾，参与者的感受。
4. **资源需求清单**：按模块写需求、数量、日期、规格，交 sourcing-costing M1。
5. **风险与应急**：天气、交通、人员、设备、安全。
6. 填 TP08 第二部分。

## M3 风格与主视觉

适用：SC18；SC13–SC16 需要视觉时。

1. 没有风格卡时，先按 TP09 做风格卡：主题关键词、色彩值、构图、字体、画面元素、禁用元素、参考图。品牌要素按 D10 §1（未提供时用中性风格）。
2. 生成主视觉、封面、概念图；或按要求编辑图片（局部修改、合成、统一风格）。
3. 每张图标"创意示意"；保存为 `{项目编号}_{用途}_{序号}_示意.{扩展名}`，同名 .md 记录平台、提示词、用途。
4. 带中文字的画面按 D10 §6 处理。
5. 列出需要人确认的视觉。

## M4 方案审查

适用：SC26 第 2 步（首版和重大修改）；SC27 终审（与需求矩阵一起看）。

逐项检查，输出"必须改"和"建议改"两类意见：

| 检查项 | 看什么 |
|---|---|
| 目标契合 | 每个主要环节是否服务于主目标 |
| 可执行 | 交通时长、场地容量、时间冲突、季节与天气 |
| 资源成立 | 写进方案的资源是否有报价或已核可用 |
| 成本受控 | 是否与成本测算版本一致；有没有隐含的额外费用 |
| 差异化 | 与同类方案相比的亮点 |
| 风险 | 安全、合规（金融客户的营销合规）、未成年人 |
| 承诺适度 | 有没有未经确认的效果、档期、价格承诺 |
| 评分覆盖 | 招投标项目：每个评分项都有对应内容 |

## M5 含糊反馈

适用：SC17。

1. 把意见拆成可以操作的维度：

| 客户说法 | 可能指的是 |
|---|---|
| 更高级 | 空间与场地档次、服务密度、稀缺体验、仪式感、视觉质感、嘉宾层级 |
| 更有特色 | 地方文化、独特场地、互动形式、主题包装 |
| 更轻松 | 节奏、自由时间、强度、正式程度 |
| 更有内容 | 讲师或嘉宾、学习环节、成果产出 |

2. 在预算和日期约束内，给出 2–3 个调整方案；每个方案标明是否需要更换或新增资源（需要时交 sourcing-costing M3、M4）。
3. 建议先向客户确认是哪一种理解（可以给出问法），再改方案。

# 客户活动策划卡

版本 v1.0 · 素材层 · 属于 planning-design（S03）

适用项目：客户沙龙、客户答谢、高净值客户活动、品牌讲座、客户维护活动。

## 1 常见客户目标

客户经营（关系维护、业务转化）；对外宣传（品牌触达）；业务交流。

## 2 必问问题

| 问题 | 为什么问 | 答案怎样改变方案 |
|---|---|---|
| 邀请对象的层级与人数 | 规格与形式 | 高净值客户更重私密和定制 |
| 活动目的：维护、转化还是品牌 | 内容取向 | 转化类需要后续跟进环节 |
| 品牌露出要求 | 视觉与物料 | |
| 合规限制（礼品价值、宣传用语、营销规定） | 金融客户的营销合规 | 礼品和话术由客户确认 |
| 邀约与签到由谁负责 | 分工 | |
| 嘉宾或讲者 | 内容 | |
| 预算与报价口径 | 方向取舍 | |

## 3 设计要素

主题与内容（讲座、体验、品鉴、亲子等）；环境与仪式感；嘉宾；礼品；邀约、签到与接待；拍摄与宣传；后续跟进（客户经理的跟进话术和名单交接）。

## 4 常用服务模块组合

M06、M03、M04、M07、M02（讲者）、M09、M11、M12。

## 5 常见风险与应对

| 风险 | 应对 |
|---|---|
| 合规风险（礼品价值、宣传用语） | 由客户合规部门确认；方案中写明 |
| 出席率低 | 邀约节奏与提醒；备用名单 |
| 隐私 | 客户名单只在表格中处理（L4）；拍摄需授权 |
| 品牌不一致 | 风格卡与客户品牌规范对齐 |

## 6 评分与客户关注点

创意与品牌契合度、执行质量、接待规格、客户体验。

## 7 参考片段

A07 中的客户活动类方案与片段。

## 8 不适用的情况

面向员工的内部活动（按会议活动卡或出行福利卡）。

# 会议活动策划卡

版本 v1.0 · 素材层 · 属于 planning-design（S03）

适用项目：工作会、经营分析会、启动会、论坛、峰会、表彰会、年会、专题活动。

## 1 常见客户目标

经营目标（统一思想、传达目标）；荣誉激励（表彰）；组织文化；业务交流；对外宣传。

## 2 必问问题

| 问题 | 为什么问 | 答案怎样改变方案 |
|---|---|---|
| 参会人数与层级（领导、嘉宾、员工） | 决定场地、座次、接待规格 | 高层多 → 接待、礼宾、保密要求提高 |
| 会议性质与议程框架 | 决定会场形式和时长 | 表彰类需要颁奖流程和舞美 |
| 日期是否可调 | 影响场地档期和价格 | 可调时给出价格更优的日期 |
| 地点要求（城市、酒店或会议中心） | 资源范围 | |
| 是否需要直播或录制 | M08、M09 | 增加技术和网络保障 |
| 嘉宾与讲者 | 接待和流程 | 外部嘉宾需要邀约与接送 |
| 预算范围与报价口径 | 方向取舍 | |
| 保密要求 | M12 | 签保密协议、限制拍摄 |

## 3 设计要素

主题与主视觉；议程节奏（开场、主体、互动、收尾）；会场布局；嘉宾接待；舞美、灯光、音响、LED；直播；物料；餐饮与茶歇；签到与引导；应急（设备故障、嘉宾变动、超时）。

## 4 常用服务模块组合

M03、M04、M05、M06、M07、M08、M09、M11、M12；表彰类加奖杯证书（M07）。

## 5 常见风险与应对

| 风险 | 应对 |
|---|---|
| 场地容量或层高不够 | 提前核场地平面图和设备条件 |
| 设备故障 | 备用设备、彩排 |
| 流程超时 | 议程预留缓冲，主持人控时 |
| 嘉宾变动 | 备选流程 |
| 泄密 | 保密协议、拍摄限制 |

## 6 评分与客户关注点

整体策划方案、创新性、响应速度、团队配置、针对性、质量控制、案例。

## 7 参考片段

A07 中的会议活动类方案与片段（按客户行业、规模筛选）。

## 8 不适用的情况

以学习为主要目的的会议（按培训学习卡）；以客户为对象的活动（按客户活动卡）。

# 培训学习策划卡

| 教学形式（讲授、演练、案例、参访） | 场地和物料 | 演练需要分组教室 |
| 教务要求（签到、作业、社群、结业） | M10 | |
| 场地与住宿标准 | M03、M04 | |
| 预算与报价口径 | 方向取舍 | |

## 3 设计要素

需求诊断；课程体系与课表；讲师匹配（主题、行业经验、风格）；教学形式；练习与作业；评估（反应、学习、行为）；教务运营；结业与证书；训后跟进。

## 4 常用服务模块组合

M01、M02、M03、M04、M10、M11、M07（教材、证书）；参访类加 M05、M15。

## 5 常见风险与应对

| 风险 | 应对 |
|---|---|
| 讲师档期冲突 | 备选讲师；提前锁定 |
| 课程版权 | 核授权范围 |
| 学员出勤率低 | 签到与提醒；与客户人力部门协同 |
| 效果难以证明 | 事先约定评估方式和指标 |

## 6 评分与客户关注点

服务方案、师资与课程、教务运营、需求诊断、案例与口碑、服务团队。

## 7 参考片段

A07 中的培训类方案、课表与讲师组合。

## 8 不适用的情况

# 出行福利策划卡

版本 v1.0 · 素材层 · 属于 planning-design（S03）

适用项目：定制游、研学、名企游学、疗休养、团建、员工福利旅行。

## 1 常见客户目标

荣誉激励；员工关怀；组织文化；队伍建设（团建）；专业能力与视野（游学、研学）。

## 2 必问问题

| 问题 | 为什么问 | 答案怎样改变方案 |
|---|---|---|
| 人数与结构（年龄、性别、领导、是否带家属或未成年人） | 住宿分配、强度、安全 | 有未成年人时加监护与安全员 |
| 出发地、日期、天数 | 线路与交通 | |
| 体力强度与节奏偏好 | 行程安排 | 疗休养类节奏要舒缓 |
| 住宿与餐饮标准、饮食禁忌 | M03、M04 | |
| 证件与出入境（如出境） | M16 | |
| 保险要求 | M12 | |
| 学习或活动目标（研学、游学、团建） | 课程、参访、任务设计 | |
| 预算与报价口径 | 方向取舍 | |

## 3 设计要素

线路与节奏（每天车程建议不超过 3 小时【默认】）；住宿；餐饮；体验项目与讲解；团队活动；自由时间；天气与季节；安全与应急。

研学、游学另加：课程目标、任务单、导师或讲解员配比、安全员配比、成果展示、家长沟通（未成年人）。

## 4 常用服务模块组合

M15、M05、M03、M04、M12、M11、M06、M09；研学、游学加 M02、M10；出境加 M16。

## 5 常见风险与应对

| 风险 | 应对 |
|---|---|
| 安全事故 | 安全员、保险、应急预案、就近医院信息 |
| 交通延误 | 缓冲时间、备选交通 |
| 天气 | 室内备选方案 |
| 健康问题 | 事先收集健康须知（L4，表格处理） |
| 未成年人监护 | 监护人与带队老师分工、点名制度 |
| 景区限流或闭园 | 提前预约，备选景点 |
| 退改损失 | 核对供应商的取消条款 |

## 6 评分与客户关注点

安全保障、线路合理、服务标准、应急预案、讲解与课程质量（研学）。

## 7 参考片段
