## 0 说明

- 本清单列出体系中的全部产物，写明位置和状态。路径相对于方法库根目录。
- **状态**：
  - **已建**：已经写好或生成，可以使用；
  - **已建·待实测**：已经写好，需要在平台上实测（兼容矩阵）；
  - **已建·待填**：结构已建，需要公司提供内容（参数、品牌、真实数据）；
  - **待提供**：需要公司或开发方提供；
  - **预留**：为未来保留，暂不建设。
- **层**：通用（通用规则层）、路由、场景、方法、素材、工具、适配、检验、治理。分层说明见 D01 §3.6。
