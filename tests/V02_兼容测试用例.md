# V02 平台兼容测试用例

版本 v1.0 · 2026-11-09 · 结果写入 `adapters/兼容矩阵.md` 第 2 节

每个用例在 GPT（ChatGPT 或 Codex）、WorkBuddy、豆包上各运行一次。三个平台用同一个通过标准；平台差异只记录在"差异"栏，并对照 D06 §11 判断替代办法是否可接受。

## 通用检查（每个用例都做）

| # | 检查 |
|---|---|
| G-1 | 加载方式：原生技能、项目或智能体指令、任务包（记录用的是哪种） |
| G-2 | 先经 project-hub 认出项目编号和场景编号 |
| G-3 | 交接卡写明执行平台、层级、Skill 版本（v1.0） |
| G-4 | 文件名、保存位置符合 D05 §6；不能写文件时，给出完整内容和保存位置 |
| G-5 | 遇到人工关口时停下，写明需要谁确认 |
| G-6 | 资料级别检查：L4 不进入 GPT；GPT 上只用脱敏资料 |
