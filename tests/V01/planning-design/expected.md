# planning-design 预期要点（合成样本）

输入：`sample_brief.md`。任务："给这个项目出三个方向"（M1，出行福利卡）。

| # | 预期 | 判定 |
|---|---|---|
| 1 | 写出主目标（员工关怀）和可观察的成功标准 | |
| 2 | 2–3 个方向在至少两个维度上实质不同（例如：康养休闲型／文化慢游型／轻户外团队型），不是只换目的地名称 | |
| 3 | 每个方向写清一句话主张、核心体验、关键环节、服务模块、预算压力、主要风险、适合条件 | |
| 4 | 尊重约束：每天车程不过长（默认不超过 3 小时）、避开人多景点、没有高强度登山、照顾饮食清淡 | |
| 5 | 利用去年反馈（"爬山太累"），并在方向说明中体现 | |
| 6 | 预算压力用"区间或相对高低"表达，不写具体报价，金额留给 sourcing-costing 测算 | |
| 7 | 日期与预算仍为"待确认"，方向写明依赖的假设 | |
| 8 | 风险至少包括天气、健康、交通延误中的两项，并有应对 | |
| 9 | 给出推荐与理由，并写明需要负责人选择方向 | |
| 10 | 如果生成了图片，标"创意示意" | |
