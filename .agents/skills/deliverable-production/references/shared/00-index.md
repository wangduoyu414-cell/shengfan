# 通用规则索引

版本 v1.0 · 2026-11-09 · 通用规则层

本目录是**通用规则层**的唯一来源：对所有项目、所有场景、所有平台都成立的规则和策略。

- 具体场景怎样走（路由路径），不写在这里，写在主 Skill「项目总控」的场景卡里。
- 某个 Skill 内部怎样做，写在该 Skill 的模式文件里。
- 场景卡和模式文件只写本场景、本模式特有的内容；涉及通用规则时引用编号（如"按 D06 §4.1"），不复制原文。

---

## 1 内容分层

| 层 | 回答什么 | 位置 | 例子 |
|---|---|---|---|
| 1 通用规则层 | 任何任务都必须遵守什么 | 本目录：D05、D06、D07、D09、D10 | 状态只由人升级；个人敏感信息不进入 GPT |
| 2 路由层 | 这句话或这个事件属于哪个场景 | project-hub/references/routing.md | "客户改了人数" → SC30 或 SC31 |
| 3 场景层 | 这个场景按什么顺序经过哪些 Skill 和模式 | project-hub/references/scenarios/ | SC02：新建 → 快速模式比对 → 复用报价 → 改写方案 → 终检 → 审批 |
| 4 方法层 | 某个 Skill 在某种模式下怎么做 | 各 Skill 的 references/modes.md | brief-analysis 快速模式的比对步骤 |
| 5 素材层 | 用什么格式、参照什么内容 | 模板 TP01–TP20、策划卡、共享资产 | 项目主卡模板、出行福利策划卡 |

事实（项目和公司的具体信息）不在任何一层里，存放在业务库和乐享（D05 §2）。

---

## 2 冲突时的优先级

1. 法律法规，客户合同和采购文件中的硬性要求
2. D07 数据分级与平台准入
3. D06 §7 人工关口
4. 其他通用规则（D05、D06、D09、D10）
5. 场景卡
6. Skill 模式
7. 模板

下层不得改写上层。发现冲突时按上层执行，并在交接卡里记录冲突。
