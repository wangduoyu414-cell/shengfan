# 成本测算表使用说明

版本 v1.0 · 方法层 · 属于 sourcing-costing（S04） ｜ 工具 X01

---

## 1 文件

- 模板：`templates/X01-cost-calculator.xlsx`（不直接填写模板，复制后使用）。
- 项目副本：`03_资源与报价/{项目编号}_成本测算_V{n}_{YYYYMMDD}.xlsx`。
- 黄色格子填写，灰色格子是公式。

## 2 工作表

| 工作表 | 内容 |
|---|---|
| 说明 | 使用方法 |
| 参数 | 项目编号、版本、计划人数、低档与高档系数（默认 0.8、1.2）、报价口径、毛利底线、风险预备比例、三档拟报价 |
| 成本明细 | 每行一个费用项（预置 100 行） |
| 汇总 | 三档的成本合计、参考价金额、待查估算金额、风险预备、最低安全报价、拟报价、毛利、毛利率、人均报价和提醒 |
| 模块 | M01–M16 |

## 3 成本明细怎样填

| 列 | 填法 | 例子 |
|---|---|---|
| 模块编号 | D05 §7 | M03 |
| 费用项 | 具体名称 | 酒店标准间（双人间） |
| 报价编号 | A04 的编号；参考价也要填来源编号 | Q-261101-01 |
| 价格状态 | 参考价、正式报价、已核可用、已锁定、已结算、已失效、待查估算 | 正式报价 |
| 单价 | 与报价的计价单位一致 | 480 |
| 计量方式 | 按人数（数量随人数变化）或固定数量 | 按人数 |
| 系数或数量 | 按人数时填每人系数；固定数量时填数量 | 0.5（两人一间） |
| 次数 | 天数、晚数或场次 | 2（两晚） |
| 向上取整 | 房间、车辆等需要整数时填"是" | 是 |
| 含税 | 是、否、未知 | 是 |

计算公式：

- 按人数：数量 = 人数 × 系数（需要时向上取整）× 次数
- 固定数量：数量 = 系数或数量 × 次数
- 小计 = 单价 × 数量

## 4 常见写法

| 费用 | 计量方式 | 系数 | 次数 | 取整 |
|---|---|---|---|---|
| 双人间住宿 | 按人数 | 0.5 | 晚数 | 是 |
| 单人间住宿 | 按人数 | 1 | 晚数 | 否 |
| 正餐 | 按人数 | 每天餐数 | 天数 | 否 |
| 45 座大巴 | 按人数 | 1/45 ≈ 0.0223 | 天数 | 是 |
| 主会场 | 固定数量 | 1 | 天数 | 否 |
| 讲师 | 固定数量 | 讲师人数 | 天数或课时 | 否 |
| 保险 | 按人数 | 1 | 天数（按天计时） | 否 |

## 5 计算结果怎样取得

- 有 Excel 或 WPS：打开文件即自动计算；保存后文件里才有计算结果。
- 没有 Excel：运行 `python3 scripts/cost_recalc.py {测算表} --out {同名}_摘要.md`（方法库中为 tools/cost_recalc.py），按同样的公式复算并输出摘要（需要 openpyxl）。
- 都不能用：输出测算输入表（Markdown），请人在表格中填写（D06 §11）。

## 6 引用

对外报价和方案中的金额都写"成本测算 V{n}"；脚本复算时写"成本测算 V{n}（脚本复算）"。不在其他文件里另算金额（D09 §1）。
