# 场景路由表

版本 v1.0 · 2026-11-09 · 路由层 · 属于 project-hub（S00）

本文件只回答一件事：**这句话或这个事件属于哪个场景，按什么路径走**。各场景的完整路径在 `scenarios/` 的场景卡里；通用规则见 `shared/`。

---

## 1 使用方法

1. 先认项目（D06 §3.1）。
2. 用第 3 节的"典型说法或事件"和"判别要点"找到唯一的场景。
3. 匹配到多个时，按第 4 节的判别规则区分；仍不能区分时，只问一个问题（第 4 节给出了问法）。
4. 打开场景卡所在的文件，按路径执行。
5. 都不匹配时，按 SC46（设计外）处理。

## 4 判别规则（容易混淆的场景）

| 混淆 | 规则 | 仍不能判断时 |
|---|---|---|
| SC01、SC02、SC03 | 有正式采购文件且不在框架内 → SC01；客户有框架资格、需求在框架范围内 → SC02；没有采购文件 → SC03 | 问："这是框架内的订单，还是新的招标？" |
| SC30、SC31 | 按 D06 §4.1 第 3 条阈值判断 | 不问，按 SC31 处理 |
| SC31、SC37 | 项目阶段为"执行中" → SC37；否则 SC31 | — |
| SC24、SC30/SC31 | 变化来自供应商 → SC24；来自客户 → SC30 或 SC31 | 问："是客户要改，还是供应商那边变了？" |
| SC17、SC30 | 方向性、笼统的意见 → SC17；具体到某一处的修改 → SC30 | — |
| SC13–SC16 | 按主卡的主产品族；有多个产品族时用主产品族的策划卡，其他作为补充 | 问："这个项目以哪类为主？" |
| SC10、SC01 | SC01 已包含参与判断；对已立项的项目单独问"投不投" → SC10 | — |
| SC09、SC47 | 问某个项目的情况 → SC09；问公司层面的资料 → SC47 | — |
| SC04、SC05、SC06 | 定时批次 → SC04；单个文件 → SC05；人手动给的纪要、录音、截图 → SC06 | — |
| SC39、SC40 | 项目已关闭 → SC39；未中选或放弃 → SC40 | — |
| SC25、SC26、SC27、SC28 | 按成果类型：报价单 → SC25；方案或 PPT → SC26；标书 → SC27；文案 → SC28 | 问："要出的是哪种文件？" |

## 5 一句话里有多个任务

按顺序拆开处理：先信息更新（A 组），再变更（F 组），最后成果（E 组）。每个任务单独写交接卡。
