# 项目总控的流程（P1–P6）

版本 v1.0 · 方法层 · 属于 project-hub（S00）

---

## P1 新建项目〔T2〕

1. **查重**：在 A01 中按客户、项目名称、日期查找，避免重复立项；框架内订单查"所属框架"下的项目。
2. **编号**：取当年最大项目编号加一（D05 §5）。同一采购中的标包、批次用子编号 -01、-02。
3. **建工作区**：能运行脚本时用 `tools/init_project.py new-project`；不能运行时按 D01 §6.2 手工建目录（00_项目主卡.md、00_项目日志.md、01_原始资料/ … _任务/）。
4. **主卡初稿**（TP01）：
   - 身份：入口类型、所属框架、产品族（按 D05 §8 判断，标"推断"）；
   - 分工设置：按平台身份声明和 D06 §2.2 填默认值；
   - 当前有效条件：已知信息一律"待确认"，写来源。
5. **日志**：第一条"事件：立项（来源……）"。
6. **回写建议**：A01 新增一行；A08 群与项目映射（新群或活跃项目）。
7. 【人】项目经理确认立项。

## P2 恢复上下文〔T2〕

1. 读主卡全文。
2. 读日志最近 10 条。
3. 读 `_任务/` 中最近一张交接卡。
4. 核对版本指针里的文件是否存在。
5. 比较主卡"沟通记录已处理到"与 02_沟通记录 中最新的摘要：有未处理内容时，提示先走 SC04。
6. 输出一段现状（用于 SC09 或任务开始前）：阶段；有效条件（只列已确认）；当前有效文件；待确认事项；下一节点；风险。

## P3 资料检索〔T2〕

1. 明确要找什么：资料类别（资质、案例、制度、介绍、价格参考……）和用途（内部参考或对外使用）。
2. 按 D05 §2.2、§2.3 确定权威位置。
3. 业务库：读 A05、A07、A01 或项目工作区。
4. 乐享，本平台已连接：
   - 先用关键词检索 `search_kb_search`；结果不理想时用语义检索 `search_kb_embedding_search`；
   - 用 `knowledge_describe_ai_parse_content` 读取正文；
   - 只用读类工具（D07 §5）。
5. 乐享，本平台未连接：在交接卡"需要的资料"中写明检索词和用途，由已连接的平台补快照（D05 §2.4）。
6. 回答时注明来源（D05 §4）和"可否对外"；检索不到时写"未检索到"，不编造。

## P4 任务包〔T2〕

按 D06 §9：

1. 填交接卡（TP03），包括"任务包说明"部分。
2. 选 Skill 指令版：`adapters/generated/{skill-name}.md`。
3. 选资料：只放完成任务需要的文件；逐份按 D07 §4 判定能否交给目标平台，需要时脱敏（D07 §3），标"脱敏版"。
4. 建文件夹 `_任务/任务包_{YYYYMMDD}_{序号}/`，放入交接卡、指令版和资料。
5. 写明产出要求：文件名（D05 §6）、格式、保存位置、回写内容。
6. 告诉发起人：把文件夹交给哪个平台、需要做什么。

## P5 收尾〔T2〕

1. 通用复核清单（D06 §10）。
2. 按 D05 §6 保存成果；正式文件只由主责平台写入（D06 §5）。
3. 回写建议：要写入主卡、日志、资产的内容，写在交接卡里，等人确认。
4. 结果类事件（中选、未中选、签约）：提出项目阶段的更新建议（D05 §3.3）。
5. 写交接卡（TP03）。

## P6 状态查询与周报〔T2〕

**单个项目的现状**：用 P2 第 6 步的格式。

**项目周报**（TP20）：

1. 从 A01 按阶段列出项目。
2. 从各项目日志取本周条目，写进展。
3. 从主卡取下一节点、超期的待确认、降级结果待审。
4. 从 A04 取即将到期的报价（7 天内）。
5. 投标统计：按口径分列金额（D05 §9.1），不相加。
6. 需要排版或图表时，交 S05·M6。
