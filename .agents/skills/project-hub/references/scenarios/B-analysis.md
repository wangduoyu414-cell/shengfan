# 场景卡 B：分析判断

版本 v1.0 · 场景层 · 属于 project-hub（S00）

---

## SC10 投标或接单判断

- **触发**："这个标值不值得投""接不接"。
- **判别**：对已立项项目的参与决定（新的采购文件走 SC01，其中已包含这一步）。
- **前置**：需求与评分矩阵已有；需要金额判断时，至少有粗略测算。
- **路径**：
  1. S02·M4〔T1〕按十个维度判断，给出"参与／不参与／有条件参与"的建议和条件
  2. 需要金额时：S04·M4〔T3〕粗测（可以用参考价，标明"估算"）
  3. 【人】负责人决定
- **回写**：日志"决定"；主卡阶段（放弃时）；A06 记录本次判断要点。

## SC11 资格与证据核对

- **触发**："我们资质够不够""业绩证明有没有"。
- **判别**：只核资格和证据，不做完整解析。
- **路径**：
  1. S02·M6〔T2〕资格条件逐条对照 A05（或乐享）：有效期、适用主体、证据状态；只有"已交付"及以上的证据可以作为业绩
  2. 输出满足项、缺口和补证建议（例如合作方资质、补开证明）
  3. 【人】决定补证或放弃
- **回写**：A05 中即将过期的证据列入待办。

## SC12 招标答疑与澄清文件

- **触发**：收到答疑、澄清、补遗文件。
- **判别**：已有需求矩阵，采购方给出了新的说明。
- **路径**：
  1. S01·M3〔T2〕归档原件
  2. S02·M5〔T1〕与需求矩阵比对，标出变化；需求版本加一
  3. 变化影响已有成果（方案、报价、标书）时：S06·M1〔T1〕列出需要修改的文件
- **回写**：TP06 新版本；主卡的需求版本指针；日志"变更：采购方澄清"。
