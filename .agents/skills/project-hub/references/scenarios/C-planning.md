# 场景卡 C：策划与视觉

SC13–SC16 的路径相同，区别在于使用哪张策划卡和第 3 步的重点。策划卡在 planning-design/references/cards/。

## SC13 会议活动策划

- **触发**："年会、论坛、启动会、表彰会怎么做"。
- **判别**：主卡的主产品族为会议活动。
- **前置**：主卡中的目标、人数、日期、预算至少有"待确认"值；缺失的先走 SC03 第 3 步。
- **路径**：
  1. S03·M1〔T1〕按会议活动卡生成 2–3 个实质不同的方向 → TP08 第一部分
  2. 【人】负责人或项目经理选方向
  3. S03·M2〔T1〕议程、环节、嘉宾接待、舞美与直播需求、资源需求清单 → TP08 第二部分
  4. S03·M3〔T1〕风格卡与主视觉（需要时）→ TP09
  5. 转 SC20（询价）和 SC26（成文）
- **回写**：主卡"选定方向"（人选定后）；04_策划与设计。

## SC14 培训项目策划

- **触发**："培训班、训练营、研修班怎么设计"。
- **判别**：主产品族为培训学习。
- **路径**：
  1. S03·M1〔T1〕按培训学习卡生成方向（学习目标、课程结构、教学形式的差异）
  2. 【人】选方向
  3. S03·M2〔T1〕课表、讲师画像与要求、教务安排、考核与结业 → TP08
  4. S04·M1〔T2〕讲师和场地询价（讲师档期和课程版权是重点）
  5. 转 SC26
- **回写**：主卡；A03 讲师档案（询价后）。

## SC15 出行类策划

- **触发**："研学、游学、定制游、疗休养、团建的行程"。
- **判别**：主产品族为出行福利。
- **路径**：
  1. S03·M1〔T1〕按出行福利卡生成方向（线路、节奏、体验和强度的差异）
  2. 【人】选方向
  3. S03·M2〔T1〕逐日行程（每天车程、用餐、住宿、体验）、安全与应急、研学的课程目标和任务（如适用）→ TP08
  4. S04·M1〔T2〕地接、酒店、车辆、门票询价（M15、M03、M05）
  5. 转 SC26
- **注意**：名单类信息按 L4 处理；有未成年人时，监护、保险、安全员配比必须写进方案。

- **触发**："客户沙龙、答谢会、高净值客户活动"。
- **判别**：主产品族为客户活动。

## SC17 含糊的方向性反馈

- **触发**："要更高级""再有特色一点""但预算不变"。
- **判别**：方向性、笼统的意见（具体到某一处的修改走 SC30）。
- **路径**：
  1. S03·M5〔T1〕把意见拆成可以操作的维度（空间、服务、稀缺性、仪式感、视觉、内容），给出 2–3 个在约束内的调整方案，并标明是否需要改资源
  2. 需要改资源：S04·M3、M4〔T1、T3〕比较和测算
  3. 不需要改资源：S05 对应模式〔T2〕改内容和视觉
  4. 【人】确认调整方案
- **回写**：主卡"方向与策略"；日志"决定"。

## SC18 风格、主视觉、图片精修

- **触发**："做个主视觉""这张图改一下"。
- **判别**：关键视觉，或需要局部修改、合成的图片编辑。
- **路径**：
  1. S03·M3〔T1〕风格卡（没有时先做）→ 主视觉、概念图或图片编辑；记录平台和提示词；标"创意示意"
  2. 【人】确认视觉
- **回写**：04_策划与设计/视觉/；A07（复盘时再决定是否入库）。
