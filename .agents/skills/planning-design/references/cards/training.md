# 培训学习策划卡

版本 v1.0 · 素材层 · 属于 planning-design（S03）

适用项目：管理干部培训、销售与绩优培训、讲师训练营（TTT）、专业研修、课程采购。

## 1 常见客户目标

销售增长；队伍建设；管理能力；专业能力；组织文化（内部知识传承）。

## 2 必问问题

| 问题 | 为什么问 | 答案怎样改变方案 |
|---|---|---|
| 学员画像（岗位、层级、人数、分班） | 课程难度与形式 | 新人与骨干的课程不同 |
| 学习目标与考核方式 | 课程结构和评估 | 需要证书时增加考核环节 |
| 课时与天数 | 课表 | |
| 是否指定讲师或课程 | M02 资源 | 指定时核档期和版权 |
| 教学形式（讲授、演练、案例、参访） | 场地和物料 | 演练需要分组教室 |
| 教务要求（签到、作业、社群、结业） | M10 | |
| 场地与住宿标准 | M03、M04 | |
| 预算与报价口径 | 方向取舍 | |

## 3 设计要素

需求诊断；课程体系与课表；讲师匹配（主题、行业经验、风格）；教学形式；练习与作业；评估（反应、学习、行为）；教务运营；结业与证书；训后跟进。

## 4 常用服务模块组合

M01、M02、M03、M04、M10、M11、M07（教材、证书）；参访类加 M05、M15。

## 5 常见风险与应对

| 风险 | 应对 |
|---|---|
| 讲师档期冲突 | 备选讲师；提前锁定 |
| 课程版权 | 核授权范围 |
| 学员出勤率低 | 签到与提醒；与客户人力部门协同 |
| 效果难以证明 | 事先约定评估方式和指标 |

## 6 评分与客户关注点

服务方案、师资与课程、教务运营、需求诊断、案例与口碑、服务团队。

## 7 参考片段

A07 中的培训类方案、课表与讲师组合。

## 8 不适用的情况

以游览、福利为主的游学（按出行福利卡，学习内容作为补充）。
