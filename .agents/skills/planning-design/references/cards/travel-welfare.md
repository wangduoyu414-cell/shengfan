# 出行福利策划卡

版本 v1.0 · 素材层 · 属于 planning-design（S03）

适用项目：定制游、研学、名企游学、疗休养、团建、员工福利旅行。

## 1 常见客户目标

荣誉激励；员工关怀；组织文化；队伍建设（团建）；专业能力与视野（游学、研学）。

## 2 必问问题

| 问题 | 为什么问 | 答案怎样改变方案 |
|---|---|---|
| 人数与结构（年龄、性别、领导、是否带家属或未成年人） | 住宿分配、强度、安全 | 有未成年人时加监护与安全员 |
| 出发地、日期、天数 | 线路与交通 | |
| 体力强度与节奏偏好 | 行程安排 | 疗休养类节奏要舒缓 |
| 住宿与餐饮标准、饮食禁忌 | M03、M04 | |
| 证件与出入境（如出境） | M16 | |
| 保险要求 | M12 | |
| 学习或活动目标（研学、游学、团建） | 课程、参访、任务设计 | |
| 预算与报价口径 | 方向取舍 | |

## 3 设计要素

线路与节奏（每天车程建议不超过 3 小时【默认】）；住宿；餐饮；体验项目与讲解；团队活动；自由时间；天气与季节；安全与应急。

研学、游学另加：课程目标、任务单、导师或讲解员配比、安全员配比、成果展示、家长沟通（未成年人）。

## 4 常用服务模块组合

M15、M05、M03、M04、M12、M11、M06、M09；研学、游学加 M02、M10；出境加 M16。

## 5 常见风险与应对

| 风险 | 应对 |
|---|---|
| 安全事故 | 安全员、保险、应急预案、就近医院信息 |
| 交通延误 | 缓冲时间、备选交通 |
| 天气 | 室内备选方案 |
| 健康问题 | 事先收集健康须知（L4，表格处理） |
| 未成年人监护 | 监护人与带队老师分工、点名制度 |
| 景区限流或闭园 | 提前预约，备选景点 |
| 退改损失 | 核对供应商的取消条款 |

## 6 评分与客户关注点

安全保障、线路合理、服务标准、应急预案、讲解与课程质量（研学）。

## 7 参考片段

A07 中的出行类行程、研学课程与任务单。

## 8 不适用的情况

以会议为主、附带短途游览的项目（按会议活动卡，游览作为补充）。
