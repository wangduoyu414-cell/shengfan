# 会议活动策划卡

版本 v1.0 · 素材层 · 属于 planning-design（S03）

适用项目：工作会、经营分析会、启动会、论坛、峰会、表彰会、年会、专题活动。

## 1 常见客户目标

经营目标（统一思想、传达目标）；荣誉激励（表彰）；组织文化；业务交流；对外宣传。

## 2 必问问题

| 问题 | 为什么问 | 答案怎样改变方案 |
|---|---|---|
| 参会人数与层级（领导、嘉宾、员工） | 决定场地、座次、接待规格 | 高层多 → 接待、礼宾、保密要求提高 |
| 会议性质与议程框架 | 决定会场形式和时长 | 表彰类需要颁奖流程和舞美 |
| 日期是否可调 | 影响场地档期和价格 | 可调时给出价格更优的日期 |
| 地点要求（城市、酒店或会议中心） | 资源范围 | |
| 是否需要直播或录制 | M08、M09 | 增加技术和网络保障 |
| 嘉宾与讲者 | 接待和流程 | 外部嘉宾需要邀约与接送 |
| 预算范围与报价口径 | 方向取舍 | |
| 保密要求 | M12 | 签保密协议、限制拍摄 |

## 3 设计要素

主题与主视觉；议程节奏（开场、主体、互动、收尾）；会场布局；嘉宾接待；舞美、灯光、音响、LED；直播；物料；餐饮与茶歇；签到与引导；应急（设备故障、嘉宾变动、超时）。

## 4 常用服务模块组合

M03、M04、M05、M06、M07、M08、M09、M11、M12；表彰类加奖杯证书（M07）。

## 5 常见风险与应对

| 风险 | 应对 |
|---|---|
| 场地容量或层高不够 | 提前核场地平面图和设备条件 |
| 设备故障 | 备用设备、彩排 |
| 流程超时 | 议程预留缓冲，主持人控时 |
| 嘉宾变动 | 备选流程 |
| 泄密 | 保密协议、拍摄限制 |

## 6 评分与客户关注点

整体策划方案、创新性、响应速度、团队配置、针对性、质量控制、案例。

## 7 参考片段

A07 中的会议活动类方案与片段（按客户行业、规模筛选）。

## 8 不适用的情况

以学习为主要目的的会议（按培训学习卡）；以客户为对象的活动（按客户活动卡）。
