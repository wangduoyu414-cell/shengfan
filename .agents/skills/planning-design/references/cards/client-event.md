# 客户活动策划卡

版本 v1.0 · 素材层 · 属于 planning-design（S03）

适用项目：客户沙龙、客户答谢、高净值客户活动、品牌讲座、客户维护活动。

## 1 常见客户目标

客户经营（关系维护、业务转化）；对外宣传（品牌触达）；业务交流。

## 2 必问问题

| 问题 | 为什么问 | 答案怎样改变方案 |
|---|---|---|
| 邀请对象的层级与人数 | 规格与形式 | 高净值客户更重私密和定制 |
| 活动目的：维护、转化还是品牌 | 内容取向 | 转化类需要后续跟进环节 |
| 品牌露出要求 | 视觉与物料 | |
| 合规限制（礼品价值、宣传用语、营销规定） | 金融客户的营销合规 | 礼品和话术由客户确认 |
| 邀约与签到由谁负责 | 分工 | |
| 嘉宾或讲者 | 内容 | |
| 预算与报价口径 | 方向取舍 | |

## 3 设计要素

主题与内容（讲座、体验、品鉴、亲子等）；环境与仪式感；嘉宾；礼品；邀约、签到与接待；拍摄与宣传；后续跟进（客户经理的跟进话术和名单交接）。

## 4 常用服务模块组合

M06、M03、M04、M07、M02（讲者）、M09、M11、M12。

## 5 常见风险与应对

| 风险 | 应对 |
|---|---|
| 合规风险（礼品价值、宣传用语） | 由客户合规部门确认；方案中写明 |
| 出席率低 | 邀约节奏与提醒；备用名单 |
| 隐私 | 客户名单只在表格中处理（L4）；拍摄需授权 |
| 品牌不一致 | 风格卡与客户品牌规范对齐 |

## 6 评分与客户关注点

创意与品牌契合度、执行质量、接待规格、客户体验。

## 7 参考片段

A07 中的客户活动类方案与片段。

## 8 不适用的情况

面向员工的内部活动（按会议活动卡或出行福利卡）。
